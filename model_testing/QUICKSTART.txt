┌──────────────────────────────────────────────────────────────────────────────┐
│ STEP 1: Setup (Einmalig)                                                    │
└──────────────────────────────────────────────────────────────────────────────┘

    $ cd model_testing
    $ ./setup.sh

    ✓ Installiert Dependencies (requests, python-dotenv)
    ✓ Erstellt .env Datei aus .env.example
    ✓ Ready to configure!

┌──────────────────────────────────────────────────────────────────────────────┐
│ STEP 2: Konfiguration                                                       │
└──────────────────────────────────────────────────────────────────────────────┘

    $ nano .env

    ┌─────────────────────────────────────────────────────────────┐
    │ # API Configuration                                         │
    │ LLM_API_KEY=sk-your-croc-api-key-here                      │
    │ LLM_API_BASE_URL=https://api.croc.com/v1                   │
    │ LLM_PROVIDER_NAME=CROC                                      │
    │                                                             │
    │ # Optional: Specific models (comma-separated)              │
    │ # Leave empty for auto-discovery                           │
    │ LLM_MODELS=                                                 │
    │                                                             │
    │ # Test Configuration                                        │
    │ TEST_RUNS_PER_CASE=3                                        │
    │ TEST_TEMPERATURE=0.3                                        │
    │ TEST_MAX_TOKENS=2000                                        │
    │ TEST_TIMEOUT_SECONDS=30                                     │
    └─────────────────────────────────────────────────────────────┘

    💡 TIP: .env wird NICHT committed (sicher!)

┌──────────────────────────────────────────────────────────────────────────────┐
│ 📊 TYPISCHE WORKFLOWS                                                        │
└──────────────────────────────────────────────────────────────────────────────┘

    Workflow 1: Erste Evaluation
    ────────────────────────────────────────────────────────────
    $ ./setup.sh                              # Setup
    $ nano .env                               # API Key eintragen
    $ ./run_model_tests.sh --list            # Modelle sehen
    $ ./run_model_tests.sh --auto-discover   # Alle testen
    → Best Overall Modell identifiziert!

    Workflow 2: Schneller Vergleich
    ────────────────────────────────────────────────────────────
    $ echo "TEST_RUNS_PER_CASE=1" >> .env
    $ python3 model_test.py --model-names "llama-3.1-8b" "gpt-4o-mini"
    → In 2 Minuten fertig!

    Workflow 3: Production Testing
    ────────────────────────────────────────────────────────────
    $ echo "TEST_RUNS_PER_CASE=5" >> .env
    $ echo "TEST_TEMPERATURE=0.0" >> .env    # Deterministisch
    $ python3 model_test.py --model-names "best-model"
    → Hochpräzise Messung!

┌──────────────────────────────────────────────────────────────────────────────┐
│ 🎯 COMMAND REFERENCE                                                         │
└──────────────────────────────────────────────────────────────────────────────┘

    Setup & Konfiguration
    ──────────────────────────────────────────────────────────
    ./setup.sh                           # Einmalig: Setup durchführen
    cp .env.example .env                 # Manuell: .env erstellen
    nano .env                            # .env editieren

    Modelle entdecken
    ──────────────────────────────────────────────────────────
    ./run_model_tests.sh --list          # Liste verfügbare Modelle
    python3 model_test.py --list-models  # Alternative

    Tests ausführen
    ──────────────────────────────────────────────────────────
    ./run_model_tests.sh --auto-discover           # Alle Modelle
    ./run_model_tests.sh                           # .env LLM_MODELS
    python3 model_test.py --model-names "llama"    # Nach Name
    python3 model_test.py --model-ids "model-id"   # Nach ID

    Override .env
    ──────────────────────────────────────────────────────────
    python3 model_test.py \
      --api-key "key" \
      --api-url "url" \
      --auto-discover

    Ergebnisse
    ──────────────────────────────────────────────────────────
    cat test_results.json                # Vollständige Ergebnisse
    cat test_results.json | jq           # Pretty-printed JSON

┌──────────────────────────────────────────────────────────────────────────────┐
│ 🚨 TROUBLESHOOTING                                                           │
└──────────────────────────────────────────────────────────────────────────────┘

    Problem: "No API key provided"
    ────────────────────────────────────────────────────────────
    → Lösung: Prüfe .env Datei existiert und LLM_API_KEY gesetzt

    Problem: "Could not auto-discover models"
    ────────────────────────────────────────────────────────────
    → Lösung: API unterstützt /models endpoint nicht
              → Nutze models_config.json stattdessen

    Problem: Rate Limiting
    ────────────────────────────────────────────────────────────
    → Lösung: TEST_RUNS_PER_CASE reduzieren oder Delay erhöhen

    Problem: Timeouts
    ────────────────────────────────────────────────────────────
    → Lösung: TEST_TIMEOUT_SECONDS in .env erhöhen
